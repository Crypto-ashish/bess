# BESS

**BESS_Value_Chain_Stages_0-7.xlsx** – battery energy storage (BESS) value chain, stages 0–7:
mining, raw materials, cells, packs & racks, BMS/EMS, PCS & electrical, system integration, EPC.

One sheet, one collapsible group per stage (+ / – on the left). For each main component:
composition, global makers, Indian makers, market share / key facts, and a source link.

Prepared after The Battery Show India 2026.

**cell-manufacturing-course/** – Li-ion cell manufacturing course, Modules 0–16 (raw materials → finished cells,
equipment, dry rooms, PFMEA, cost model for 1/5/10 GWh plants, global and Indian ecosystem). Markdown modules,
a combined PDF and an Excel cost model. Start at `cell-manufacturing-course/README.md`.
